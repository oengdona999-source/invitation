# Invitation frontend recreation

Open index.html in a browser. HTML, CSS and JavaScript are editable without a build step.

Reference: https://e.sambot.co/kampongspeu_gendarmerieroyal/phlkm

Images, fonts and reference CSS were exported from the browser's observed page assets. The implementation uses new HTML/CSS/JavaScript; it is not the original Next.js project or server source. Original exported CSS files are retained in assets for reference.

The three animation videos use the original remote CDN URLs because browser asset export failed for those files. YouTube and the location link also require internet. Greetings are stored locally and are not sent to the reference website. Audio is not included. The page is a frontend recreation, with layout and animation timing approximated.
